## Goal

Patch 19 high-severity (and 10 moderate) transitive-dependency advisories surfaced by
`pnpm audit --audit-level=high` by pinning forward the affected packages via
`pnpm.overrides`. The advisories exist on main today — main's last push pre-dated the
advisories being published — so PR #1's failure is a symptom of a baseline gap, not
something PR #1 introduced.

## Context Files

- [x] `package.json` — add `pnpm.overrides` block under the existing `pnpm` config
- [x] `pnpm-lock.yaml` — regenerated by `pnpm install` after overrides are added
- [x] `.github/workflows/ci.yml` — `audit` job runs `pnpm audit --audit-level=high` on
      every PR + push to main (read-only, no edit)

## Constraints

- No source-code changes; this is a dependency-baseline fix only.
- `pnpm.overrides` syntax pins by semver range (e.g. `"@xmldom/xmldom@<0.8.13": "^0.8.13"`)
  rather than top-level versions — none of the affected packages are direct deps.
- All 7 vulnerable packages must be covered: `@xmldom/xmldom`, `fast-uri`, `flatted`,
  `glob`, `minimatch`, `picomatch`, `underscore`.
- Lockfile must regenerate cleanly under `pnpm install --frozen-lockfile` (CI flag).
- Pre-commit hook: ≤15 staged files, lowercase conventional commits, check:spec,
  lint-staged. This commit stages exactly 3 files: this spec, `package.json`,
  `pnpm-lock.yaml`.
- Never `--no-verify`, never `SKIP_SPEC_CHECK=1`.

## Implementation Plan

1. Create `chore/pnpm-overrides-audit-fix` branch off main.
2. `git stash pop` to restore the prepared `pnpm.overrides` + lockfile diff (already
   staged earlier as `stash@{0}`).
3. `pnpm install --frozen-lockfile` — confirms the stashed lockfile matches the overrides.
   If frozen-lockfile fails (drift), re-run without `--frozen-lockfile` to refresh.
4. `pnpm audit --audit-level=high` → expect "No high or critical vulnerabilities found"
   or equivalent exit 0.
5. `pnpm typecheck && pnpm lint && pnpm build` — sanity check that no transitive bump
   introduced an API break.
6. `git add plans/task-2026-05-12-pnpm-overrides-audit-fix.md package.json pnpm-lock.yaml`
   then commit with `chore: pin transitive deps to fix high-severity audit advisories`.
7. `git push -u origin chore/pnpm-overrides-audit-fix` and `gh pr create --base main`.
8. After merge: PR #1's branch (`feat/scf-2026-1-1-pivot`) needs main merged in so the
   audit job re-runs against the patched lockfile.
